| Field | Value |

> **For AI agents:** this file is the single source of truth for **entity names, field names, types and constraints**. Domain classes, SQLite tables, DTOs and OpenAPI schemas must use these names (DTOs in camelCase JSON). If a story needs a new field: add it here first (PR), then code. Do **not** create parallel models of the same concept (e.g. two different `Room` classes).

## 1. Conventions

| Topic | Convention |
|---|---|
| Table names | PascalCase plural (`Rooms`, `RoomPhotos`). Join tables `<A><B>s` (`RoomAmenities`). |
| Primary keys | `Id TEXT` = `Guid.NewGuid().ToString("N")` (32 lowercase hex), generated by the domain factory — same as existing `Users`. Reference tables may use a short code as key. |
| Money | `INTEGER` VND (no decimals). Column suffix `Vnd`. |
| Area / coordinates | `REAL`. Area in m² (1 decimal); `Latitude`/`Longitude` WGS84 decimal degrees. |
| Date-time | `TEXT` ISO-8601 UTC (`2026-11-11T08:30:00.0000000Z`), suffix `Utc`. Date-only `TEXT` `yyyy-MM-dd`. Time-of-day `TEXT` `HH:mm`. |
| Booleans | `INTEGER` 0/1, prefix `Is`/`Has`/`Needs`. |
| Enums | `TEXT` holding the C# enum **name** (e.g. `'PendingReview'`) — readable and order-independent; validated with `Enum.IsDefined` + whitelist (GUARDRAILS 1.5.1). |
| Concurrency | Mutable aggregates have `Version INTEGER NOT NULL DEFAULT 1`. `UPDATE … SET …, Version = Version + 1 WHERE Id = @Id AND Version = @Version`; 0 rows → `ConcurrencyConflictException` (409). Domain exposes it as `string ConcurrencyToken` (= `Version.ToString()`), API as `ETag: "<version>"`. |
| Ownership | User-owned rows carry the owner FK (`UserId`, `LandlordId`, `StudentId`) and every query on them filters by it (anti-IDOR, GUARDRAILS 1.5.6). |
| Soft delete | Not used. Listings are never deleted in MVP (state `Unpublished`); other user data is hard-deleted. |
| SQLite pragmas | `journal_mode=WAL`, `foreign_keys=ON`, `busy_timeout=5000`. |
| Migrations | Ordered SQL scripts applied by a small runner using `PRAGMA user_version` ([ADR-002](adr/adr-002-sqlite-single-datastore.md)). |

## 3. Aggregates (domain ↔ tables)

**Aggregates** — `RoomToRentRadar.Domain/Aggregates/`, edited concurrently by users ⇒ table has `Version`, class exposes `ConcurrencyToken` (enforced by `ArchitectureTests.DomainAggregates_MustDeclareConcurrencyTokenProperty`):

| Aggregate root | Owned entities / VOs | Tables | Stories |
|---|---|---|---|
| `User` *(exists)* | `RefreshTokenSession`, `EmailAddress` | `Users`, `UserRefreshTokens` | US13 |
| `Room` | `Money`, `GeoPoint`, `Address`, `Utilities`, `HouseRules` (VO per version), amenity/safety code sets | `Rooms`, `RoomAmenities`, `RoomSafetyFeatures`, `HouseRuleVersions` | US01-05, 08, 10, 11 |
| `SavedSearch` | `SearchCriteria` VO, `GeoPolygon` VO | `SavedSearches` | US05, US07 |
| `ListingReport` | — | `ListingReports` | US12 |

**Entities** — `RoomToRentRadar.Domain/Entities/`, no `Version` (append-only, idempotent, owned by one writer, or system-written); still validate invariants in constructors:

| Entity | Why no `Version` | Tables | Stories |
|---|---|---|---|
| `RoomPhoto` | uploaded once; attach uses a conditional update (§4.8) | `RoomPhotos` | US03, US08 |
| `Favourite` | idempotent insert/delete | `Favourites` | US06 |
| `Conversation`, `ConversationParticipant` | only system fields change (last message, read time) | `Conversations`, `ConversationParticipants` | US14 |
| `Message` | append-only | `Messages` | US14 |
| `SavedSearchAlertLog` | append-only, idempotent key | `SavedSearchAlertLogs` | US07 |
| `DeviceRegistration` | idempotent upsert | `DeviceRegistrations` | US07, US14 |
| `Notification` | system-written; only `IsRead` flips | `Notifications` | US07, US14 |
| `TravelTimeEstimate` | cache | `TravelTimeEstimates` | US09 |
| `Campus` | reference data | `Campuses` | US01, US09 |
| `AuditLogEntry` *(exists)* | append-only | `AuditLogs` | cross-cutting |

### 4.8 `RoomPhotos`
| Column | Type | Constraints | Notes |
|---|---|---|---|
| Id | TEXT | PK | |
| RoomId | TEXT | FK→Rooms | null until attached (BR-MED-03) |
| UploadedByUserId | TEXT | FK→Users, NN | ownership |
| Kind | TEXT | NN | `Standard`·`Panorama` |
| ContentType | TEXT | NN | `image/jpeg`·`image/png` (magic-byte checked) |
| SizeBytes | INTEGER | NN | ≤ 10,485,760 |
| Width | INTEGER | NN | |
| Height | INTEGER | NN | |
| OriginalPath | TEXT | NN | storage key, e.g. `rooms/2026/11/<id>/original.jpg` |
| MediumPath | TEXT | NN | 1280 px |
| ThumbPath | TEXT | NN | 400 px |
| SortOrder | INTEGER | NN | 0 = cover |
| CreatedAtUtc | TEXT | NN | |
| AttachedAtUtc | TEXT | | |

IX `(RoomId, SortOrder)`, IX `(UploadedByUserId, AttachedAtUtc)` for cleanup of unattached > 24 h.

Attach is race-safe without a `Version` column: `UPDATE RoomPhotos SET RoomId = @roomId, SortOrder = @order, AttachedAtUtc = @now WHERE Id = @id AND UploadedByUserId = @me AND (RoomId IS NULL OR RoomId = @roomId)`; fewer rows updated than requested ids → the whole create/update fails with `400 VALIDATION_FAILED` (photo not owned, expired, or attached elsewhere). Run inside the same transaction as the listing insert/update.

## 5. Client-side cache (SQLite on device)

Separate file `roomtorentradar-cache.db3` in `FileSystem.AppDataDirectory`; schema owned by the client adapters project ([ADR-004](adr/adr-004-client-offline-cache.md)). Contains **no** secrets (tokens live in `SecureStorage`).

| Table | Key | Content | Expiry |
|---|---|---|---|
| `CachedQueries` | `QueryKey` (hash of endpoint + params) | JSON payload of a page, `ETag`, `FetchedAtUtc` | first page of last 5 queries; 24 h |
| `CachedRoomDetails` | `RoomId` | JSON `RoomDetailDto`, `ETag`, `FetchedAtUtc` | last 50 viewed; 7 days |
| `CachedFavourites` | `RoomId` | JSON `FavouriteDto` | mirror of server |
| `PendingOperations` | `Id` | queued offline mutations (favourite add/remove, chat send) with `IdempotencyKey`, `CreatedAtUtc` | until sent |
| `CompareTray` | `RoomId` | `AddedAtUtc` | — (BR-CPR-01) |
| `CachedConversations` / `CachedMessages` | `Id` | last 50 messages per conversation | 30 days |
| `ListingDrafts` | `DraftId` | landlord wizard draft JSON (UC-30 A1) | 30 days |

Preferences (`Preferences` API, not SQLite): `SelectedCampusId` (guest), `HasCompletedOnboarding`, `SeenHouseRules:<roomId>`, `InstallationId`.
