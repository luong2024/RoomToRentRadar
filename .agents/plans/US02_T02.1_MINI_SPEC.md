## 1. ACCEPTANCE CRITERIA (AC) MAPPING & VERIFICATION
- **AC1:** Trả về đầy đủ thông tin: description, rent, deposit, area, room type, amenities, address, landlord contact (name, phone), house rules, photos, 360 panorama.
  - *Status:* Verified via `GetRoomDetailUseCaseTests` and `RoomDetailEndpointIntegrationTests`.
- **AC2:** Trả về trạng thái bài đăng (`Status`) và thời gian cập nhật gần nhất (`LastUpdatedAt`).
  - *Status:* Verified via `GetRoomDetailUseCaseTests`.
- **AC3:** Nếu phòng không khả dụng (`Unavailable` hoặc `Rented`), hệ thống trả về thông báo (`UnavailableMessage`) và gợi ý các phòng tương tự (`SimilarRooms: IReadOnlyList<RoomCardDto>`).
  - *Status:* Verified via `GetRoomDetailUseCaseTests` and `RoomDetailEndpointIntegrationTests`.
- **AC4:** Chỉ người dùng đã đăng nhập (`IsAuthenticated == true`) mới nhận được số điện thoại chủ trọ (`LandlordPhoneNumber`). Khách vãng lai nhận `null`.
  - *Status:* Verified via `GetRoomDetailUseCaseTests` and `RoomDetailEndpointIntegrationTests`.

## 2. COMPONENT INVENTORY & ARTIFACTS

### 2.1. Domain Layer (`RoomToRentRadar.Domain`)
- `Entities/Room.cs`: Encapsulated domain entity with invariant protection (Guardrail 1.5.3).
- `Enums/RoomStatus.cs`: `Available`, `Unavailable`, `Rented`, `PendingVerification`.

### 2.2. Ports Layer (`RoomToRentRadar.Ports`)
- `Contracts/Responses/Rooms/RoomCardDto.cs`: Summary DTO for room cards and similar room suggestions.
- `Contracts/Responses/Rooms/RoomDetailDto.cs`: Comprehensive room details DTO.
- `Inbound/UseCases/Rooms/IGetRoomDetailUseCase.cs`: Single-method driving port (`ExecuteAsync`).
- `Outbound/Repositories/IRoomRepository.cs`: Driven port for room data access (`GetByIdAsync`, `GetSimilarRoomsAsync`).
- `Outbound/Security/ICurrentUserContext.cs`: Driven port for ambient user authentication state.

### 2.3. Application Layer (`RoomToRentRadar.Application`)
- `UseCases/Rooms/GetRoomDetailUseCase.cs`: Implements `IGetRoomDetailUseCase`, orchestrating retrieval, privacy rules, and fallback suggestions.
- `Mappers/RoomMapper.cs`: Pure mapping logic between domain entities and response DTOs.
- `DependencyInjection.cs`: Registers `IGetRoomDetailUseCase` -> `GetRoomDetailUseCase`.

### 2.4. Infrastructure Layer (`RoomToRentRadar.Infrastructure`)
- `Adapters/Mocks/InMemoryRoomRepository.cs`: Thread-safe in-memory repository with realistic ICTU room seed data.
- `Adapters/Mocks/InMemoryCurrentUserContext.cs`: Mock ambient user context.
- `DependencyInjection.cs`: Binds `IRoomRepository` and fallback `ICurrentUserContext`.

### 2.5. Web API Layer (`RoomToRentRadar.Api`)
- `Controllers/RoomsController.cs`: REST Controller exposing `GET /api/rooms/{id}`.
- `Security/HttpContextUserContextAdapter.cs`: Production adapter reading claims from `IHttpContextAccessor`.
- `Program.cs`: Wires up `HttpContextAccessor` and `ICurrentUserContext`.

### 2.6. Test Suite (`RoomToRentRadarUnitTests`)
- `Application/Rooms/GetRoomDetailUseCaseTests.cs`: 12 domain/use-case unit tests.
- `Api/RoomsControllerTests.cs`: 7 controller unit tests.
- `Api/RoomDetailEndpointIntegrationTests.cs`: 5 end-to-end vertical slice tests.
- Total solution tests: 134/134 passing (including 10 Architecture tests and 100 Auth/Audit tests).
