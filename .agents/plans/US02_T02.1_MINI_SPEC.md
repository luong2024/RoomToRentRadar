# MINI-SPEC: US02 / T02.1 - Build Room Detail API
> **User Story:** US02 — As a student, I want to view the full details of a room so that I can decide whether it suits me.  
> **Task ID:** T02.1 — Build room detail API (description, amenities, rules)  
> **Author:** Tran Thuy Duyen  
> **Role:** Lead Orchestrator & Core Domain Specialist  
> **Architectural Pattern:** Hexagonal Architecture (Ports & Adapters) + Clean Architecture

---

## 1. ACCEPTANCE CRITERIA (AC) MAPPING
- **AC1:** Trả về đầy đủ thông tin: description, rent, deposit, area, room type, amenities, address, landlord contact (name, phone), house rules, photos, 360 panorama.
- **AC2:** Trả về trạng thái bài đăng (`Status`) và thời gian cập nhật gần nhất (`LastUpdatedAt`).
- **AC3:** Nếu phòng không khả dụng (`Unavailable` hoặc `Rented`), hệ thống trả về thông báo (`UnavailableMessage`) và gợi ý các phòng tương tự (`SimilarRooms: IReadOnlyList<RoomCardDto>`).
- **AC4:** Chỉ người dùng đã đăng nhập (`IsAuthenticated == true`) mới nhận được số điện thoại chủ trọ (`LandlordPhoneNumber`). Khách vãng lai nhận `null`.
