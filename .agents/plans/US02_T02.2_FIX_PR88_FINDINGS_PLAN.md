### Vấn đề 1: Rò rỉ bộ nhớ (Memory Leak) do đăng ký static event không giải phóng
- **Vị trí:** `RoomToRentRadar/PageModels/RoomDetailPageModel.cs:268`
- **Hiện trạng:**
  ```csharp
  LocalizedStrings.Instance.PropertyChanged += (_, _) => OnCultureChanged();
  ```
  `LocalizedStrings.Instance` là singleton tĩnh, trong khi `RoomDetailPageModel` là Transient. Việc đăng ký lambda nắm giữ tham chiếu `this` vĩnh viễn khiến Garbage Collector không thể thu hồi các instance ViewModel cũ.
- **Giải pháp:**
  1. Trong `RoomDetailPageModel.cs`: Triển khai interface `IDisposable`.
  2. Lưu handler tường minh `private readonly PropertyChangedEventHandler _cultureChangedHandler;`.
  3. Đăng ký handler trong constructor và hủy đăng ký (`-=`) trong phương thức `Dispose(bool disposing)`.
  4. Trong `RoomDetailPage.xaml.cs`: Đăng ký `Unloaded += (s, e) => _viewModel.Dispose();` để đảm bảo khi Page đóng hoặc bị pop khỏi Navigation Stack, toàn bộ tài nguyên và sự kiện được giải phóng dứt điểm.
  5. Bổ sung Unit Test xác minh việc hủy đăng ký sau khi gọi `Dispose()`.

### Vấn đề 2: `LocalizedStringsExtension` trả về chuỗi tĩnh làm mất khả năng đổi ngôn ngữ động
- **Vị trí:** `RoomToRentRadar/Resources/Strings/LocalizedStrings.cs:38-53`
- **Hiện trạng:**
  `LocalizedStringsExtension` hiện đang triển khai `IMarkupExtension<string>`, trả về chuỗi text cố định tại thời điểm nạp XAML. Khi người dùng đổi ngôn ngữ tại Settings (US15), các tiêu đề tĩnh không tự động render lại.
- **Giải pháp:**
  1. Chuyển `LocalizedStringsExtension` sang triển khai `IMarkupExtension<BindingBase>`:
     ```csharp
     #if !UNIT_TESTS
     [ContentProperty(nameof(Key))]
     [AcceptEmptyServiceProvider]
     public class LocalizedStringsExtension : IMarkupExtension<BindingBase>
     {
         public string Key { get; set; } = string.Empty;

         public BindingBase ProvideValue(IServiceProvider serviceProvider)
         {
             return new Binding($"[{Key}]", source: LocalizedStrings.Instance);
         }

         object IMarkupExtension.ProvideValue(IServiceProvider serviceProvider)
         {
             return ProvideValue(serviceProvider);
         }
     }
     #endif
     ```
  2. Tận dụng cơ chế indexer `this[string key]` và sự kiện `PropertyChanged` của `LocalizedStrings` để giao diện MAUI tự động re-bind khi culture thay đổi.
