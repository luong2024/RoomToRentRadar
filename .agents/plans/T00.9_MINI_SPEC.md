## 1. Mục tiêu & Nghiệp vụ (Business Rules)

Task **T00.9** mở rộng Aggregate Root `Room` và tầng cơ sở dữ liệu SQLite để lưu trữ đầy đủ 3 nhóm thông tin con của phòng trọ:
1. **Tiện nghi (Amenities - `docs/erd.md` §4.5):**
   - Danh mục mã tiện nghi chuẩn theo `Amenity` enum (15 tiện nghi: `AirConditioner`, `WaterHeater`, `PrivateBathroom`, `Wifi`, `Kitchen`, `WashingMachine`, `Fridge`, `Bed`, `Wardrobe`, `Desk`, `Balcony`, `Window`, `MotorbikeParking`, `Elevator`, `DryingArea`).
   - Lưu trữ tại bảng join `RoomAmenities (RoomId, AmenityCode)`.
   - Invariants: Mỗi tiện nghi trong phòng là duy nhất (tập hợp `HashSet`/`IReadOnlySet`), mã tiện nghi phải thuộc danh mục cho phép (whitelist validation).

2. **Tính năng an toàn & PCCC (Safety Features - `docs/erd.md` §4.6, `BR-LST-08`):**
   - Danh mục tính năng an toàn theo `SafetyFeature` enum (5 tính năng: `Cctv`, `SecureEntrance`, `FireSafety`, `OwnerOrGuardOnSite`, `WellLitAccess`).
   - Lưu trữ tại bảng `RoomSafetyFeatures (RoomId, FeatureCode, IsConfirmed)`.
   - Nghiệp vụ (`BR-LST-08`):
     - Khi Chủ nhà khai báo / chỉnh sửa thêm tính năng an toàn: các tính năng được lưu với `IsConfirmed = false` (0), và nếu phòng đang hiển thị sẽ kích hoạt `NeedsReReview = true`.
     - Khi Admin duyệt phòng (`Approve`): Admin xác nhận các tính năng an toàn đã kiểm chứng, đặt `IsConfirmed = true` (1).
     - Điểm an toàn (`SafetyScore`): Khi phòng đã xác thực an toàn (`IsSafetyVerified = true`), điểm bằng tổng số tính năng có `IsConfirmed = true`. Nếu chưa xác thực (`IsSafetyVerified = false`), hiển thị số tính năng tự khai báo dưới dạng "Chưa xác minh".

3. **Nội quy nhà theo phiên bản bất biến (House Rules - `docs/erd.md` §4.7, `BR-HR-01`, `BR-HR-02`):**
   - Lưu trữ tại bảng `HouseRuleVersions`.
   - Mỗi lần cập nhật nội quy, hệ thống **không ghi đè** mà tạo một bản ghi mới với `VersionNumber` tự tăng (`VersionNumber = CurrentVersion + 1`) (`BR-HR-02`).
   - Nghiệp vụ xác thực (`BR-HR-01`):
     - `QuietHoursStart`, `QuietHoursEnd`, `CurfewTime`: định dạng thời gian `HH:mm` (chuỗi hoặc null).
     - `GuestPolicy`: Enum `Allowed`, `DaytimeOnly`, `NotAllowed`.
     - `CookingPolicy`: Enum `Allowed`, `SharedKitchenOnly`, `NotAllowed`.
     - `ParkingAvailable`: `bool` (0/1).
     - `ParkingRules`: Chuỗi văn bản $\le 300$ ký tự.
     - `PetsAllowed`, `SmokingAllowed`: `bool` (0/1).
     - `OtherRules`: Chuỗi văn bản $\le 1,000$ ký tự.
     - `CreatedByUserId`: ID người tạo (Chủ nhà / Admin), không được rỗng.
     - `CreatedAtUtc`: Thời điểm tạo (UTC).

## 2. Thiết kế Kiến trúc & Hợp đồng Dữ liệu

### 2.1. Cấu trúc Bảng SQLite (`0003_room_children.sql`)

```sql
CREATE TABLE RoomAmenities (
    RoomId TEXT NOT NULL,
    AmenityCode TEXT NOT NULL,
    PRIMARY KEY (RoomId, AmenityCode),
    FOREIGN KEY (RoomId) REFERENCES Rooms(Id) ON DELETE CASCADE
);

CREATE TABLE RoomSafetyFeatures (
    RoomId TEXT NOT NULL,
    FeatureCode TEXT NOT NULL,
    IsConfirmed INTEGER NOT NULL DEFAULT 0,
    PRIMARY KEY (RoomId, FeatureCode),
    FOREIGN KEY (RoomId) REFERENCES Rooms(Id) ON DELETE CASCADE
);

CREATE TABLE HouseRuleVersions (
    Id TEXT PRIMARY KEY NOT NULL,
    RoomId TEXT NOT NULL,
    VersionNumber INTEGER NOT NULL,
    QuietHoursStart TEXT NULL,
    QuietHoursEnd TEXT NULL,
    CurfewTime TEXT NULL,
    GuestPolicy TEXT NOT NULL,
    GuestPolicyNote TEXT NULL,
    CookingPolicy TEXT NOT NULL,
    ParkingAvailable INTEGER NOT NULL,
    ParkingRules TEXT NULL,
    PetsAllowed INTEGER NOT NULL,
    SmokingAllowed INTEGER NOT NULL,
    OtherRules TEXT NULL,
    CreatedByUserId TEXT NOT NULL,
    CreatedAtUtc TEXT NOT NULL,
    FOREIGN KEY (RoomId) REFERENCES Rooms(Id) ON DELETE CASCADE,
    FOREIGN KEY (CreatedByUserId) REFERENCES Users(Id),
    UNIQUE (RoomId, VersionNumber)
);

CREATE INDEX IX_HouseRuleVersions_RoomId ON HouseRuleVersions(RoomId);
```

### 2.3. Persistence & Repositories (`RoomToRentRadar.Datastore.Sqlite` & `Infrastructure`)
1. **`SqliteRoomRepository`:**
   - `GetByIdAsync`: Đọc Aggregate `Room` cùng toàn bộ child rows từ 3 bảng con.
   - `AddAsync`: Thực thi transaction lưu `Rooms`, `RoomAmenities`, `RoomSafetyFeatures`, `HouseRuleVersions`.
   - `UpdateAsync`: Thực thi transaction với Optimistic Concurrency check (`Version = @expectedVersion`). Đồng bộ `RoomAmenities`, `RoomSafetyFeatures`, chèn các `HouseRuleVersions` mới.
2. **`InMemoryRoomRepository`:**
   - Sao chép toàn bộ child collections trong `Copy(...)` nhằm đảm bảo nguyên tắc Liskov Substitution Principle (LSP).
