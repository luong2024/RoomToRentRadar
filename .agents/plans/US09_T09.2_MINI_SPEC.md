## 3. Locked-Down Contract Table

### 3.1. `RoomToRentRadar.Client.Adapters`
- **`Http/HttpRoomGateway.cs`:**
  ```csharp
  public async Task<TravelTimesDto> GetRoomTravelTimesAsync(
      string roomId,
      string? campusId = null,
      CancellationToken ct = default)
  ```
  - Throws `ArgumentException` if `roomId` is null/whitespace.
  - Requests `/api/rooms/{Uri.EscapeDataString(roomId)}/travel-times` (appending `?campusId={Uri.EscapeDataString(campusId)}` when `!string.IsNullOrWhiteSpace(campusId)`).
  - Deserializes via `ApiResponseReader.ReadAsync<TravelTimesDto>(response, _logger, ct)`.
- **`Mocks/MockRoomGateway.cs`:**
  - `GetRoomTravelTimesAsync` mirrors `MockTravelTimeAdapter` + `GetRoomTravelTimesUseCase` deterministically:
    - `straightKm = Distance(campus, room)`
    - `effectiveKm = Math.Max(0.2, straightKm)`
    - `drivingMeters = Math.Max(200, (int)Math.Round(effectiveKm * 1.3 * 1000.0, MidpointRounding.AwayFromZero))`
    - `drivingSeconds = Math.Max(60, (int)Math.Round((drivingMeters / 1000.0) / 30.0 * 3600.0, MidpointRounding.AwayFromZero))`
    - `busSeconds = (int)Math.Round(drivingSeconds * 1.6, MidpointRounding.AwayFromZero) + 600`
    - `walkingMeters = Math.Max(150, (int)Math.Round(effectiveKm * 1.15 * 1000.0, MidpointRounding.AwayFromZero))`
    - `walkingSeconds = Math.Max(120, (int)Math.Round((walkingMeters / 1000.0) / 5.0 * 3600.0, MidpointRounding.AwayFromZero))`
    - Returns `new TravelTimesDto(campus.Id, straightKm, IsFallback: false, items)` with `Motorbike` (`isEstimate: false`), `Bus` (`isEstimate: true`), `Walking` (`isEstimate: false`).

### 3.2. `RoomToRentRadar` (MAUI)
- **Resources (`AppResources.resx` & `AppResources.vi.resx`):**
  - `RoomDetail_DistanceKm`: `"{0} km"` (en) / `"{0} km"` (vi)
  - `RoomDetail_DistanceMeters`: `"{0} m"` (en) / `"{0} m"` (vi)
- **Display Model (`Pages/Controls/RoomDetail/Models/RoomDetailModels.cs`):**
  ```csharp
  public sealed record CommuteModeItem(
      TravelMode Mode,
      string IconGlyph,
      string TimeFormatted,
      string DistanceFormatted,
      string Label);
  ```
- **View (`Pages/Controls/RoomDetail/LocationTravelTimesControl.xaml`):**
  - 3-column `Grid` binds `IsVisible="{Binding HasTravelTimes}"`.
  - Each mode card shows: `IconGlyph` (`ActionPrimary`), `TimeFormatted` (`TextPrimary`, bold), `DistanceFormatted` (`TextSecondary`, caption/body), `Label` (`TextSecondary`, badge).
  - `StraightLineNotice` binds `IsVisible="{Binding IsCommuteFallback}"` with `TextSecondary` color.
- **PageModel (`PageModels/RoomDetailPageModel.cs`):**
  - Constructor: `(IRoomGateway roomGateway, ISessionStore sessionStore, IFavouriteGateway? favouriteGateway = null, ISearchCriteriaStore? searchCriteriaStore = null)`
  - Campus resolution helper `ResolveCampusContextAsync()`: sets `_effectiveCampusId` and `CampusName` from `CampusId` -> `_searchCriteriaStore?.Current.CampusId` -> `CachedUserProfile?.SelectedCampusId` -> `"ICTU"`.
  - `ApplyTravelTimes(TravelTimesDto? travel)` (called by `LoadTravelTimesAsync` and `OnCultureChanged` via cached `_lastTravelTimes`):
    - If `travel is null || travel.IsFallback || travel.Items.Count == 0`:
      - `CommuteTimes.Clear()`, `HasTravelTimes = false`, `IsCommuteFallback = true`.
      - `StraightLineNotice = string.Format(CultureInfo.CurrentCulture, AppResources.GetString("RoomDetail_StraightLineNotice"), (travel?.StraightLineDistanceKm ?? Room?.DistanceKm ?? 0).ToString("0.0", CultureInfo.CurrentCulture), CampusName)`.
    - Else:
      - `IsCommuteFallback = false`, `HasTravelTimes = true`, populate `CommuteTimes` with `TimeFormatted` + `DistanceFormatted` (`FormatDistance(item.DistanceMeters)`) + localized mode `Label`.
