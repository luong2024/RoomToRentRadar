## 2. Acceptance Criteria & Business Rule Mapping

| Rule / AC | Requirement in `T09.1` |
|---|---|
| **US09 AC1 / BR-TRV-01 / BR-TRV-02** | Return distance (`distanceMeters`) and duration (`durationSeconds`) for all 3 modes: `Motorbike` (`driving-car`), `Walking` (`foot-walking`), `Bus` (`drivingDurationSeconds * 1.6 + 600`, `distanceMeters = drivingDistanceMeters`, `isEstimate = true`). `Motorbike` and `Walking` have `isEstimate = false`. |
| **US09 AC2 / BR-CMP-01..03** | Campus resolution order: (1) explicit `campusId` query param (trimmed; unknown -> `400 CAMPUS_NOT_FOUND`); (2) if `campusId` is null/whitespace and `_currentUserContext.IsAuthenticated`, read `user.SelectedCampusId` via `IUserRepository.GetByIdAsync` (if user found and campus exists); (3) default campus `ICTU` via `ICampusRepository.GetDefaultCampusAsync`. |
| **US09 AC3 / BR-TRV-04 / ADR-007** | Routing call enforces **3-second** timeout (`TimeSpan.FromSeconds(3)`). On timeout, HTTP error, quota exhaustion (429), network error, or invalid ORS payload, return `200 OK` with `TravelTimesDto(campus.Id, straightLineDistanceKm, isFallback: true, items: [])`. Straight-line Haversine uses `HaversineDistanceCalculator.CalculateDistanceKm` (0.1 km precision). Fallback is **never** cached. |
| **BR-TRV-03 / ERD §4.15** | Cache valid entries per `(RoomId, CampusId, Mode)` for **30 days** (`ComputedAtUtc >= clock.UtcNow.AddDays(-30)`). Cache is invalidated for `RoomId` whenever `UpdateListingUseCase` changes `Latitude` or `Longitude`. |
| **BR-LST-04a (Anti-IDOR)** | `Available`, `Rented`, `Unpublished` rooms are accessible to anyone; `PendingReview`, `Rejected`, `Suspended` return `404 ROOM_NOT_FOUND` unless caller is owner or `Admin`. Missing room returns `404 ROOM_NOT_FOUND`. |
| **GUARDRAILS §1.5.4 / ADR-007** | `Routing:UseMock` defaults to `false` in `appsettings.json` and `AddInfrastructure(..., bool useMockRouting = false)`. Non-Development environments throw `InvalidOperationException` at startup if `UseMock == true` or `OpenRouteServiceApiKey` is blank. |
| **ADR-012 / openapi.yaml** | Response matches `TravelTimesDto` (`campusId`, `straightLineDistanceKm`, `isFallback`, `items`) with camelCase JSON and string enum `TravelMode`. Errors use `application/problem+json` + `ProblemCodes`. |

### 3.3. `RoomToRentRadar.Application`
- **Use Case (`UseCases/Rooms/GetRoomTravelTimesUseCase.cs`):**
  - Implements `IGetRoomTravelTimesUseCase` (only 1 public method `ExecuteAsync` per `ArchitectureTests`).
  - Dependencies: `IRoomRepository`, `IUserRepository`, `ICampusRepository`, `ICurrentUserContextPort`, `ITravelTimeCacheRepository`, `ITravelTimePort`, `IClock`.
  - Bus calculation helper (private static):
    - `busDurationSeconds = (int)Math.Round(driving.DurationSeconds * 1.6, MidpointRounding.AwayFromZero) + 600`
    - `busDistanceMeters = driving.DistanceMeters`

  - Cache validity rule: must contain all 3 modes (`Motorbike`, `Bus`, `Walking`) and all entries must satisfy `entry.ComputedAtUtc >= _clock.UtcNow.AddDays(-30)`.
- **Shared Campus Resolution Helper (internal static in `Application/UseCases/Rooms/`):**
  - Eliminates duplication between `GetRoomDetailUseCase` and `GetRoomTravelTimesUseCase`.
  - Resolves `campusId` -> authenticated `user.SelectedCampusId` -> `GetDefaultCampusAsync()`.
- **`UpdateListingUseCase` (`UseCases/Landlord/UpdateListingUseCase.cs`):**

  - Detect `bool pinMoved = !room.Latitude.Equals(listing.Location.Latitude) || !room.Longitude.Equals(listing.Location.Longitude);` before `room.UpdateDetails(...)`.
  - Inside `UpdateRoomAndPhotosAsync` (same `IUnitOfWork` transaction): if `pinMoved`, call `await _travelTimeCacheRepository.InvalidateByRoomIdAsync(room.Id, innerCt)`.
- **DI (`Application/DependencyInjection.cs`):**
  - `services.AddScoped<IGetRoomTravelTimesUseCase, GetRoomTravelTimesUseCase>();`

### Phase 1 — RED Tests (`@QA`)

   - Cache expired (>= 30 days) -> calls `ITravelTimePort`, computes Bus (`driving * 1.6 + 600`), upserts cache, returns `isFallback = false` with 3 modes.

5. **`Application/Rooms/GetRoomDetailUseCaseTests.cs`:** Authenticated user with non-default `SelectedCampusId` resolves that campus when `campusId == null`.
6. **`Infrastructure/OpenRouteServiceTravelTimeAdapterTests.cs`:** Using stub `HttpMessageHandler`:
